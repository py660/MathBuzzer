# Quickstart

Dependencies: `Node16`, `Python3`
```sh
# Clone
git clone https://github.com/py660/MathBuzzer.git
cd MathBuzzer

# Install deps
npm install
pip install -r requirements.txt # aiohttp, python-socketio

# Build
npm run build

# Serve
PORT=6600 python3 main.py
```
